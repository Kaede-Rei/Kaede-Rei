## Core Competencies

- **Embedded Control Architecture**  
  Bare-metal / RTOS system architecture, BSP layering, driver abstraction, and multi-actuator coordination

- **Communication & Device Integration**  
  CAN / SCI / wireless links, communication protocol implementation, multi-device coordination, and hardware bring-up

- **Manipulator Modeling & Motion Solving**  
  MDH modeling, forward/inverse kinematics, pose reachability handling, and environment-aware planning

- **Control Interfaces & Task Frameworks**  
  Controller abstraction, command dispatching, system interface design, end-effector integration, and task-chain organization

- **Embodied Manipulation**  
  Teleoperation data collection, dataset construction, policy training and inference deployment, with LeRobot / ACT / SmolVLA real-robot workflows

- **Engineering Verification & Toolchains**  
  CMake / Ninja, ARM GNU Toolchain, FSP / RASC, MATLAB-based verification, and Python-assisted bring-up and debugging
